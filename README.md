# Monk Studio Homebrew tap

```sh
brew tap monk-studio/tap
brew install --cask monk-studio/tap/<name>
```

| Cask | App |
| --- | --- |
| `cdr` | [CDR](https://github.com/monk-studio/cd-ripper): insert a CD, get a perfect copy in your own library |
| `launcher` | [Launcher](https://github.com/monk-studio/launcher): native Spotlight replacement with Keep Awake |

Each app's release script updates its cask here.
